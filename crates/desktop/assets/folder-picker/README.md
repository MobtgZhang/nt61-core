# Folder picker icons

The six unmodified 16×16 PNGs come from Tango Icon Theme 0.8.90.
The upstream `COPYING` releases its icons into the public domain.

Source archive: https://archive.debian.org/debian/pool/main/t/tango-icon-theme/tango-icon-theme_0.8.90.orig.tar.gz

Archive SHA-256: `6e98d8032d57d818acc907ec47e6a718851ff251ae7c29aafb868743eb65c88e`

The original members under `tango-icon-theme-0.8.90/16x16/` are

- `devices/computer.png`
- `devices/drive-harddisk.png`
- `places/folder.png`
- `places/user-desktop.png`
- `places/user-home.png`
- `mimetypes/x-office-address-book.png`

The tree uses the Tango address-book icon for Libraries and the home icon for
the current user profile.
