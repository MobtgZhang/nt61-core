# Shared upstream icon notices

Google Material Design Icons, copyright Google LLC, Apache License 2.0 (`LICENSE`).
`sources.json` retains upstream URLs, revision and original source hashes. Original SVGs live in each owning application's `resources/upstream.svg`; unused historical editor artwork lives in `unused/`.

Each application owns its current `resources/icon.svg`, generated raster sizes and ICO. Current artwork attribution and hashes are in that application's `provenance.json`. Notepad, WordPad, Paint and the command-line application icons use original NT61 artwork under their local `icon-LICENSE.txt`. Ribbon artwork is original NT61 artwork generated by `scripts/generate-application-toolbars.py`. No Microsoft application icon binaries are bundled.
