# Diskpart resources

Original NT61 artwork; see `icon-LICENSE.txt`.

`icon.svg` is the editable application-owned source. `icon.ico` contains 16, 24, 32, 48, 64 and 256 pixel PNG entries for PE resources; matching PNG/RGBA files serve the desktop renderer. Regenerate with `scripts/generate-application-icons.py` from the repository root.
